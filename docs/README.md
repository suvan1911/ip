## Command aliases

LenZaBot accepts shorter aliases for commonly used commands. The aliases have
the same arguments and produce the same responses as their full command names.

| Alias | Full command |
|---|---|
| `t` | `todo` |
| `d` | `deadline` |
| `e` | `event` |
| `ls` | `list` |

For example, `t read book` is equivalent to `todo read book`.
